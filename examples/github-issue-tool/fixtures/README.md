# GitHub issue fixtures

These selective fixtures derive from the [GitHub OpenAPI description](https://github.com/github/rest-api-description/blob/7dee0622aeecf9df3c5060ca28c7a57ee5007804/descriptions/api.github.com/api.github.com.json), revision `7dee0622aeecf9df3c5060ca28c7a57ee5007804`, inspected on 2026-10-09. Requests use API version `2022-11-28`.

| Fixture or derived group                                                                          | JSON location at that revision                                                                                                                                                     | Changes                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `issue.json`, string/null/omitted body, pull-request variants                                     | `components.schemas.issue`, `components.examples.issue`                                                                                                                            | Fabricated names, IDs, URLs, and content. Keep selected fields and representative unused fields; omit the remaining issue properties. Add/remove optional `body` and `pull_request` in the tests. |
| `responses.json` redirect (301) and not-found (404)                                               | `paths["/repos/{owner}/{repo}/issues/{issue_number}"].get.responses`, `components.responses.moved_permanently`, `components.responses.not_found`, `components.schemas.basic-error` | Keep documented statuses and the message/documentation URL shape. Replace messages with private sentinels; omit other error properties and redirect headers because the tool never follows them.  |
| `responses.json` unavailable (503)                                                                | Modeled application test, outside the endpoint's documented responses                                                                                                              | Deliberately malformed body. This is neither a captured response nor a guaranteed GitHub response.                                                                                                |
| `responses.json` malformed and invalid successes; test-created read, transport, and sink failures | Deliberate faults                                                                                                                                                                  | Invalid JSON, invalid selected output, and synthetic rejected values. These do not describe valid provider responses.                                                                             |

The test token is conspicuously fake. No fixture contains real credentials or issue data. Tests read committed files only and have no network fallback. Fixture refresh is an explicit maintainer action.
